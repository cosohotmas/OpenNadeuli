# 코스 결과 지도와 카드 순서

## Why
사용자가 같은 방문지의 상세 카드와 요약 목록을 두 번 읽지 않고 지도에서 전체 방문 순서를 먼저 확인할 수 있어야 한다.

## Goal
- React와 엘리스 백업의 코스당 지도 섹션 1개, 방문 상세 카드 목록 1개를 표시한다.
- 별도 동선 요약 목록과 아래 지도 영역은 0개로 유지한다.
- 범위 제외는 코스 추천과 좌표 선별 방식 변경이다.

## What
- 완료 로그·응답 요약·조건 태그 다음에 지도를 표시하고, 상세 카드 바로 아래에 안심 체크포인트를 둔다.
- 카드의 지도 링크는 같은 코스의 핀이 준비된 경우 지도 위치로 스크롤하고 해당 핀과 팝업을 연다. 핀이 없으면 기존 장소별 지도 링크를 사용한다.
- 지도 핀 버튼은 장소 팝업을 열며 초대장 데이터는 기존 전체 방문 순서를 유지한다.

## How
- React는 코스별 지도 핸들, 엘리스 백업은 동선 렌더 함수의 핸들을 통해 방문 번호로 연결한다.
- 사용자가 새 탭 단축키를 사용하면 링크 기본 동작을 유지한다.

## AC
- Given 부산 코스 11개. When 결과가 표시된다. Then 지도, 11개 상세 카드, 안심 체크포인트 순이며 요약 행은 0개다.
- Given 좌표가 있는 상세 카드. When 지도에서 보기를 누른다. Then 같은 코스 지도로 이동하고 같은 번호의 핀과 팝업을 연다.
- Given 좌표가 없거나 아직 조회 중. When 지도에서 보기를 누른다. Then 장소별 지도를 열 수 있다.
