# 첫 화면 빠른 질문

## Why
첫 화면에서 동일 질문이 두 위치에 반복된다.

## Goal
첫 화면과 초기화 후에는 빠른 질문 한 묶음만 보인다. 실제 응답의 후속 질문은 범위에서 제외한다.

## What
인사말 아래 중복 추천을 숨기고 입력창 위 빠른 질문을 계속 제공한다.

## How
React와 정적 백업에서 초기 인사말 렌더링에만 빠른 질문을 생략한다.

## AC
- 첫 화면과 초기화 후 각 기본 추천이 한 번씩 표시된다.
- 검색 후 하단 빠른 질문이 다시 활성화된다.

## 위치 권한 후속 개선
권한이 허용되는 순간 좌표 요청을 다시 시작한다. 브라우저가 위치를 반환하지 못하면 탭 세션에 최근 확인한 시·도가 있는 경우 이를 먼저 적용한다. 좌표는 저장하지 않는다. 질문과 직접 선택 지역은 우선한다.
