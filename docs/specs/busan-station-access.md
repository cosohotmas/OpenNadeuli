# 부산 도시철도 경유 참고 정보

## Why
부산 나들이 중 역을 이용하는 가족이 역별 접근성 설비를 확인할 수 있어야 한다.

## Goal
공식 응답 114개 역을 코드로 연결하고, 각 장소에 직선 600m 이내에서 가장 가까운 역의 설치 정보를 안내한다. 실제 이동 경로와 실시간 가동 상태는 범위에서 제외한다.

## What
카드에 인근 역을, 안심 체크포인트에 역별 중복 없는 정보를 표시한다. 가족 초대장에 해당 역의 엘리베이터·경사로를 요약한다.

## How
부산교통공사 API의 역외부코드를 국가철도공단의 [전국 도시철도 역사 위치 원본](https://data.kric.go.kr/rips/M_01_01/detail.do?id=32)에서 추출한 좌표와 매칭한다. 배포 파일은 20260630 배포본의 부산교통공사 114개 행 중 역번호·역명·노선·위도·경도·기준일을 보존한다. 설치 개수가 양수인 항목을 표시하고, 장애 발생 시 기본 코스 결과를 유지한다.

## AC
- 부산에서 좌표가 있는 장소에 근접 역이 있으면 출처·조회 시각과 설비 칩이 표시된다.
- 다른 지역, 좌표가 없는 장소, API 장애에는 추정 역이나 추정 설비가 추가되지 않는다.
- 공공 좌표와 직선거리 기준임을 표시하고, 장소 자체의 접근성 안내와 구분한다.
