# 검색 진행과 현재 위치 지역

## Why
조회 중 진행 상태와 결과 시작점을 확인하고, 지역이 생략된 질문에서는 가까운 지역의 공공데이터를 조회한다.

## Goal
두 화면에서 요청 분석부터 읽을 수 있게 하고, 명시·선택·현재 위치·기본 지역의 우선순위를 구분한다. 현재 위치 기반 정밀 반경 검색은 범위에서 제외한다.

## What
요청 분석과 공공데이터 조회 상태를 표시한다. 조회 기록, 결과, 지도가 차례로 등장한다. 명시 지역이 없으면 선택 지역 또는 브라우저 위치로 판단한 시·도를 사용한다.

## How
공통 프런트엔드 유틸리티와 스타일을 사용한다. 카카오 역지오코딩에는 소수점 셋째 자리로 반올림한 좌표만 전달하고 코스 API에는 지역명만 전달한다.

## AC
- 검색 직후 새 답변 상단에 진행 상태가 표시된다.
- 모션 감소 설정에서 등장 애니메이션을 건너뛴다.
- 위치 오류·거부 시 기본 지역을 명시하고 직접 선택할 수 있다.
- 지역을 지정한 질문에는 위치 권한을 요청하지 않는다.
