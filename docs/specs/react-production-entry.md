# React 운영 화면과 엘리스 백업

## Why
운영 구현을 React, TypeScript, CSS로 유지하면서 엘리스 최종본으로 검증한 화면과 코스 동작을 제공한다.

## Goal
- 운영 `/`는 React를, `/elice-final.html`은 실행 가능한 정적 백업을 제공한다.
- 두 화면의 부산 기본 요청이 같은 11개 방문 항목과 방문 순서를 반환한다.
- 범위 제외는 공공데이터 실시간 연동, 샘플 확충 및 별도 서버 배포다.

## What
- React에서 추천 입력, 도구 단계, 일별 슬라이더, 카페·식사·숙소, 무장애 카드, 인라인 지도와 초대장을 제공한다.
- 백업 화면은 기존 HTML·CSS·Vanilla JS 진입점에서 독립 실행된다.

## How
- 화면 코드에서 DOM과 무관한 엘리스 코스 엔진을 분리해 두 진입점에서 공유한다. React는 타입이 있는 어댑터를 통해 동일한 요청과 응답을 사용한다.
- Vercel은 두 HTML 진입점을 정적으로 빌드하고 기존 FastAPI 경로를 유지한다. 공개 빌드에는 프로젝트 ZIP과 공공 API 키 입력을 포함하지 않는다.

## AC
- Given 동일 일정과 부산 요청을 두 진입점에 입력한다. When 반환된 결과를 비교한다. Then 추천 순서, 무장애 정보와 초대장이 동일하다.
- Given GitHub PR. When Vercel 프리뷰를 연다. Then 운영 예정 경로는 React로 렌더링되고 백업 URL과 API도 응답한다.
