# 3번째 버전 기준 일정과 동선 요약

## Why

당일과 1박 2일을 계획하는 사용자가 가능한 시간에 맞춰 장소와 숙소를 검토하고 방문 순서대로 지도를 열 수 있어야 한다.

## Goal

- 당일은 1일, 1박 2일은 최대 2일의 추천을 카드와 동선 목록에 순서대로 표시한다.
- 일정이 지정된 요청의 각 방문 시작 시각은 해당 날짜의 지정 범위 안에 있어야 한다.
- 숙소가 있는 지역의 1박 2일 요청에서 숙소 포함을 선택하면 1일차 숙소 카드 1개를 반환한다.
- 범위 제외는 지도 SDK 렌더링, 이동 시간·영업시간 검증, 샘플에 없는 카페 생성이다.

## What

- 입력창 위 접이식 영역에서 여행 유형, 1·2일차 시작·종료 시각, 식사, 숙소 포함을 설정한다.
- 대상 시간대와 데이터에 맞는 장소만 보여 준다. 2일차에는 앞서 추천한 장소를 반복하지 않는다.
- 응답의 방문 순서를 동선 요약과 초대장에 사용한다. 지도 링크와 시각 없이 들어온 기존 응답도 렌더링한다.

## How

- 기존 schedule 필드와 샘플 필터를 재사용한다. 0~24시 정수 범위를 받으며 시작은 종료보다 작아야 한다.
- 일별로 오전 관광지, 점심 11~14시, 오후 산책, 숙소를 시작 시각 기준으로 배치한다. 샘플 재고가 적으면 하루를 비워 둘 수 있다.
- 기존 카드에 `day`, `time`을 선택 필드로 추가하고 `route.points`에서 같은 카드를 사용한다.

## AC

- Given 부산 1박 2일, 1일차 09~18시, 2일차 09~17시, 식사와 숙소 포함. When 요청한다. Then 숙소가 1일차 마지막에 나오며 오전·오후 활동을 날짜별로 표시한다.
- Given 부산 당일 14~18시와 식사 제외. When 요청한다. Then 14시 이전 카드와 식당, 숙소가 표시되지 않는다.
- Given 시작과 종료가 같거나 순서가 잘못됐다. When 제출한다. Then UI가 오류를 표시하고 API는 잘못된 범위를 거부한다.
