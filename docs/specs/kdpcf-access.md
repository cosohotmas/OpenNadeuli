# 한국사회보장정보원 편의시설 연동

## Why
숙소를 고르고 동선을 준비하는 이용자가 추가 공공 원본에서 편의시설을 확인할 수 있어야 한다.

## Goal
이름과 도로명 주소가 일치하는 숙소를 연결하고 동선 방문 지점에서 400m까지 후보를 표시한다. 실시간 설비 작동 여부와 보행 경로 판정은 범위에서 제외한다.

## What
숙소 카드와 안심 체크포인트에 KDPCF 기구표와 출처를 표시한다. 식당 접근성은 별도로 유지한다.

## How
XML 목록을 시설명 또는 도로명으로 조회하고 후보의 시설 ID로 평가 항목을 조회한다. 이름·주소 중복 후보는 숙소 매칭에서 제외한다. 인근 시설은 공식 좌표 간 직선거리로 제한한다. 보조 조회 실패에도 기본 코스는 반환한다.

## AC
- 동일 이름·주소의 숙소에만 기구표가 연결된다.
- 400m 이내 시설의 긍정 추정 없이 명시된 기구표 항목과 조회 시각을 표기한다.
- 키 미설정 또는 API 장애에도 기본 코스·식당 확인 메모가 반환된다.
