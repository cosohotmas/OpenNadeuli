# 추천 코스의 방문 장소 조합

## Why

초기 추천 버튼은 관광지, 식당, 산책로를 순서대로 보여 줬다. 현재 백엔드는 관광지만 반환해 같은 부산 버튼에서 한 장소만 표시된다.

## Goal

- 부산 바다 데크길 예시는 오전, 점심, 오후 카드 3개를 반환한다.
- 대상 지역 밖 장소는 0개를 반환한다.
- 범위 제외는 여러 경유지를 한 지도에 그리기, 실시간 데이터 연동, 일정 편집이다.

## What

- 일반 요청은 관광지, 턱 없는 식당, 경사도 조건을 충족한 산책로를 순서대로 최대 하나씩 추천한다.
- 실내 전용 요청은 야외 산책로를 제외한다. 조건에 맞는 후보가 없으면 해당 시간대를 생략한다.
- 관광지 목록 요청은 기존 목록을 유지하고 식당 전용 요청은 식당만 표시한다.

## How

- 기존 샘플 필터를 사용한다. 탐방로의 기관명과 식당 주소에 요청 지역이 포함된 후보를 사용한다.
- 같은 세부 지역의 후보를 우선하며 카드 배열을 방문 순서로 반환한다.

## AC

- Given 부산 바다 데크길 예시. When 코스를 요청한다. Then 오전 관광지, 점심 식당, 오후 산책 카드 3개를 반환한다.
- Given 제주 요청. When 제주 샘플로 코스를 만든다. Then 부산·서울의 식당과 탐방로를 반환하지 않는다.
