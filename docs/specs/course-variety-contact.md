# 코스 후보 다양성과 연락처

## Why
같은 조건을 다시 조회하는 이용자가 다른 적격 장소를 볼 수 있고, 카드에서 실제 전화 연결 가능 여부를 알 수 있다.

## Goal
같은 API 응답으로도 2개 이상의 코스 조합을 만들 수 있다. 외부 연락처 조회 및 카카오 장소 ID 매칭은 범위에서 제외한다.

## What
적격 후보의 순서를 섞고 장소별 후보 범위와 안내를 유지한다. 유효한 원본 연락처가 있을 때만 전화 링크를 표시한다.

## How
관광지 조회 목록과 업종 필터를 통과한 반경별 식음료 목록을 샘플링한다. 두 프런트는 공통 연락처 검증과 안내 문구를 사용한다.

## AC
- 동일 코스를 반복 조회할 때 여러 후보가 선택될 수 있다.
- 번호가 없거나 형식이 잘못된 카드에 전화 링크와 전화 아이콘이 없다.
- 형식에 맞는 원본 번호는 tel 링크로 표시되고 카카오맵 검색·주소·좌표 링크가 유지된다.
