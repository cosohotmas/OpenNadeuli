# 위치 권한 대기와 지역 선택기

## Why
권한 창을 읽는 동안 기본 지역 검색이 먼저 시작되면 이용자가 실제 위치를 반영하지 못한다.

## Goal
자동 모드는 좌표 판정, 거부 또는 최대 30초 권한 대기 후 요청한다. 지연된 성공에는 재검색을 제공한다.

## What
권한 대기, 좌표 수신, 지역 판정 및 실패 이유를 안내한다. 현재 위치와 시·도는 같은 필 형태 선택기에서 고른다.

## How
두 화면은 위치 확인 헬퍼와 네이티브 details·라디오 기반 선택기를 공유한다. 진단 값만 API에 전달한다.

## AC
- 권한 허용 후 지역 결과를 받은 뒤 코스 API를 호출한다.
- 거부 또는 시간 초과를 구분해 서울 폴백을 표시한다.
- 시간 초과 후 늦게 지역이 확인되면 현재 위치 재검색 버튼을 제공한다.
- Enter, Tab, 방향키, Escape로 선택기를 조작한다.
