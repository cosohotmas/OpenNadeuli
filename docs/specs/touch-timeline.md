# 모바일 시간대 슬라이더

## Why

모바일 사용자가 시간 숫자를 직접 입력하지 않고 여행 가능한 범위를 선택하고, 전송 전에 어떤 활동을 요청할지 확인한다.

## Goal

- 일별 시작과 종료를 두 개의 터치·키보드 슬라이더에서 1시간 단위로 조절한다.
- 시작과 종료 사이 간격을 1시간 이상 유지한다.
- 시간대에 겹치는 도구만 요청당 종류별 최대 1회 호출한다.
- 범위 제외는 시간별 영업·이동 시간 계산과 공공 API 실시간 연동 변경이다.

## What

- 표시 시간은 00:00~24:00이다. 핸들을 움직이면 범위와 예상 활동이 즉시 표시된다.
- 09~11시는 오전 산책, 11~14시는 점심 식사, 14~19시는 오후 관광으로 안내한다. 각 구간은 시작 포함, 종료 제외다.
- 식사 옵션을 끄면 식당 도구를 호출하지 않는다. 실내 요청은 탐방로 도구를 제외한다. 식당·관광지 목록 요청은 해당 도구만 시간 범위에 맞춰 호출한다.
- 기존 1박 2일 숙소 옵션은 1일차 범위에 17시가 포함될 때 적용한다. 가능한 활동이 없으면 그 사실을 안내한다.

## How

- 일정 요청 스키마를 유지한다. 일정 미지정 요청은 기존 코스 조합을 유지한다.
- 일정 요청의 활동별 시간 겹침을 먼저 계산하고, 필요한 기존 도구만 호출한 뒤 결과를 시간순으로 조립한다. 지역 밖 샘플 장소를 제외한다.
- 기본 HTML range 두 개에 터치 영역과 키보드용 라벨을 제공한다. 슬라이더 값, 범위 및 활동 안내는 같은 상태에서 계산한다.

## AC

- Given 부산 09~14시와 식사 포함. When 코스를 요청한다. Then 탐방로와 상권정보 도구만 각각 1회 호출한다.
- Given 부산 14~18시. When 코스를 요청한다. Then 열린관광지 도구만 호출한다.
- Given 부산 00~08시. When 코스를 요청한다. Then 도구 호출 0회와 선택 가능한 활동 없음 안내를 반환한다.
- Given 모바일에서 시작 또는 종료 슬라이더를 조작한다. When 선택 범위가 변한다. Then 값과 예상 활동 안내가 즉시 갱신된다.
