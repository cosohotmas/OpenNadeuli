# 카카오맵 전체 동선

## Why

3번째 버전의 전체 동선 지도에서 여러 방문지를 한 화면으로 확인할 수 있었다. React의 동선 요약에서도 방문 위치와 순서를 함께 보여 준다.

## Goal

- 두 개 이상의 위치를 찾으면 한 지도에 번호가 붙은 방문지를 2개 이상 표시한다.
- 키가 비어 있거나 위치를 못 찾아도 기존 동선 목록과 장소별 링크를 이용할 수 있다.
- 범위 제외는 내비게이션 경로, 실제 이동 시간, 카카오 도메인 관리다.

## What

- 코스 카드 아래 동선 요약에 카카오맵을 표시한다.
- 찾은 방문지 모두에 번호를 붙인다. 모든 위치를 찾았을 때 방문 순서를 점선으로 연결한다.
- 일부만 찾으면 찾은 지점 수를 알린다. 연결선은 방문 순서를 표시한다.

## How

- Vite에서 프로젝트 루트의 `OPENNADEULI_MAPKAKAO` 한 항목을 읽는다. 이 항목에는 도메인이 제한된 카카오 JavaScript 키를 사용한다.
- 카카오맵 SDK의 장소 검색, 지도, 오버레이 기능을 사용한다.
- 장소 이름이 일치하는 결과를 우선한다. 이름 검색이 실패하면 주소나 탐방로 출발점으로 좌표를 조회하고 지도에서 사용한 기준을 안내한다. 기존 장소별 링크와 방문 목록을 유지한다.

## AC

- Given 키와 도메인이 등록됐고 장소 좌표를 모두 조회했다. When 동선 요약을 본다. Then 방문지 번호와 순서 연결선이 한 지도에 표시된다.
- Given 키나 좌표가 없거나 SDK를 불러오지 못했다. When 동선 요약을 본다. Then 방문 목록 링크를 이용할 수 있다.
