# 모바일 코스 조회 공간

## Why
작은 화면의 상단·하단 고정 영역이 길면 코스 내용을 한 번에 읽기 어렵다.

## Goal
720px 이하에서 헤더와 입력부의 높이를 줄이고 입력·전송·초기화는 44px 이상 터치 영역을 유지한다. 결과 카드 디자인 변경은 범위에서 제외한다.

## What
첫 화면 추천은 펼쳐두고 검색 시 접는다. 결과를 읽으며 추천을 다시 열 수 있다.

## How
두 화면에 공통 모바일 스타일을 적용한다. 검색 시 추천 접힘 상태와 접근성 속성을 갱신한다.

## AC
- 모바일에서 검색 후 추천 목록은 접히고 추천 검색 버튼으로 다시 열린다.
- 대화 초기화 시 모바일 목록이 다시 펼쳐진다.
- 데스크톱에서는 추천 목록이 계속 표시된다.
