# 엘리스 최종본 운영 반영

## Why
운영 사용자에게 사용자가 확정한 엘리스 최종본의 화면과 시간대별 코스 조합을 제공한다.

## Goal
- 운영 빌드의 첫 화면과 코스 추천, 일정, 무장애 설명, 동선, 초대장을 최종본으로 제공한다.
- 기존 API 헬스 체크와 코스 경로를 유지한다.
- 범위 제외는 공개 API 키 입력 및 소스 ZIP 배포다. 운영 데이터 기준은 최종본 내장 샘플이다.

## What
- 최종본의 HTML, CSS, 코스 조합, 일정 조작, 무장애 설명, 지도와 초대장을 적용한다.
- 카카오 JavaScript 키는 기존 운영 빌드 환경에서 읽는다. 지도 실패 시 장소별 링크를 표시한다.

## How
- 최종본을 별도 Vite 운영 진입점으로 가져온다. 정적 UI의 앱 기능과 API 배포는 기존 라우팅에서 제공한다.
- 내장 ZIP 및 브라우저 공공데이터 키 설정을 제외하고 내장 샘플의 출처 표시를 유지한다.

## AC
- Given 운영 URL. When 부산 기본 추천을 누른다. Then 최종본의 방문 목록, 무장애 설명과 초대장 버튼이 표시된다.
- Given Vercel 운영 빌드. When 카카오 지도 SDK를 불러온다. Then 해당 공개 SDK 키만 사용하고 다른 환경 파일을 배포에 포함하지 않는다.
- Given 운영 API. When 헬스 체크를 호출한다. Then 200 JSON을 반환한다.
