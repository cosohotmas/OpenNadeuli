# 코스 카드 정보 칩

## Why
이동 중 장소 카드를 훑어보는 이용자가 출처와 접근성 확인 항목을 빠르게 찾는다.

## Goal
두 카드 화면에서 메타데이터를 한 칩 그룹으로 표시한다. 데이터 판정과 지도 동작 변경은 범위에서 제외한다.

## What
기본 카드에는 출처·업종·접근성 항목·확인 안내를 표시한다. 조회 시각과 원본 문구는 접힌 상세에서 볼 수 있다.

## How
두 화면은 같은 표시 규칙과 CSS를 사용한다. 항목 칩은 원본에 등재된 정보 범주를 표시한다. 세부 값과 부정 응답은 원문 그대로 유지한다.

## AC
- 상권 카드에는 기준월, 업종, 기존 확인 안내를 칩으로 표시한다.
- 원본 접근성 값이 있으면 항목 칩을 표시하고 상세에서 정확한 값을 읽을 수 있다.
- 상세를 닫은 상태에서 ISO 시각과 원문 문단은 표시되지 않는다.
- 기존 지도·길찾기 버튼과 오프라인 실행이 유지된다.
