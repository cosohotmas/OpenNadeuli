# 동선 지도 순서 복원

## Why
코스 카드를 읽기 전에 전체 동선을 확인할 수 있어야 한다.

## Goal
두 화면에서 지도 블록이 첫 장소 카드보다 앞선다. 지도 자체의 동작 변경은 범위에서 제외한다.

## What
요청 분석과 조회 기록, 동선 지도, 장소 카드 순으로 표시한다. 검색 직후 응답 상단에서 읽기 시작한다.

## How
React와 정적 백업 모두 렌더 순서를 유지하고 조회 기록 이후에는 별도의 짧은 등장 간격을 둔다.

## AC
- 결과의 첫 장소 카드 위에 전체 동선 요약이 있다.
- 조회 기록이 많은 경우에도 지도는 카드보다 먼저 등장한다.
- 검색 완료 시 응답의 요청 분석 상단이 보인다.
