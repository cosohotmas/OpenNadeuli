# 추천 지도와 초대장

## Why

초기 오픈나들이에서 추천 장소를 지도에서 확인하고 가족에게 공유할 수 있었다. React 코스 카드에도 이 흐름을 제공한다.

## Goal

- 이름이 있는 카드마다 지도 링크 1개를 표시한다.
- 카드가 있는 응답마다 편집·복사 가능한 초대장 1개를 제공한다.
- 범위 제외는 API 키 설정, 지도 SDK 및 외부 메시지 자동 전송이다.

## What

- 장소 이름과 주소로 네이버 지도 검색을 열 수 있다.
- 추천 장소 목록을 초대장으로 열고 수정한 뒤 복사할 수 있다.
- 추천 장소가 없으면 초대장을 제공하지 않는다. 복사 실패 시 직접 복사 안내를 표시한다.

## How

- 카드의 이름과 주소를 사용해 초기 버전과 같은 네이버 지도 검색 URL을 만든다.
- 응답에 초대장 텍스트가 있으면 사용한다. 빈 값이면 추천 카드의 이름과 주소를 목록으로 만든다.
- 브라우저 기본 대화상자와 클립보드 API를 사용한다.

## AC

- Given 추천 카드 1개 이상. When 지도 링크를 확인한다. Then 해당 장소의 이름과 주소가 인코딩된 검색 URL이 있다.
- Given 추천 카드 1개 이상. When 초대장을 열고 수정한 뒤 복사를 누른다. Then 수정한 텍스트가 클립보드에 복사된다.
