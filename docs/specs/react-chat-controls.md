# React 채팅 조작 복구

## Why

사용자가 추천 예시를 눌러도 요청이 전송되지 않고, 대화 초기화 버튼은 아무 동작도 하지 않는다.

## Goal

- 추천 예시 1회 클릭과 직접 입력 1회 제출이 각각 코스 요청 1건을 보낸다.
- 초기화 1회로 첫 화면을 복원한다.
- 범위 제외는 공개 API 키 설정과 초기 버전의 일정·지도·공유 기능이다.

## What

- 추천 예시와 후속 제안은 누르면 즉시 전송한다.
- 대화에 사용자의 입력을 표시하고 초기화 시 입력, 결과, 오류를 지운다.
- 전송 중에는 중복 전송과 초기화를 막는다. 공개 화면의 동작 없는 API 설정 버튼을 제거한다.

## How

- 추천 버튼과 폼은 기존 `postCourse` 호출을 공유한다.
- 초기화는 기존 환영 메시지를 재사용한다.

## AC

- Given 첫 화면. When 추천 예시를 한 번 누른다. Then 사용자 메시지와 추천 카드가 표시된다.
- Given 결과가 표시된다. When 대화 초기화를 누른다. Then 초기 환영 메시지만 표시되고 입력이 비워진다.
- Given 요청이 진행 중이다. When 추천이나 초기화를 시도한다. Then 추가 요청이나 초기화가 발생하지 않는다.
