# 전체 코스 요약과 인라인 지도

## Why
사용자가 초대장 없이도 방문 순서와 무장애 정보, 장소 위치를 확인할 수 있어야 한다.

## Goal
- 방문 항목마다 번호, 시각, 주소, 무장애 정보가 있는 요약 행 1개를 보여 준다.
- 좌표를 확인한 방문 항목에 번호 핀을 표시하고 연속으로 좌표가 있는 구간을 순서대로 연결한다.
- 핀에서 이름, 시각, 무장애 정보가 든 말풍선을 열 수 있다.
- 범위 제외는 도로 길찾기 계산 및 좌표 추정이다.

## What
- 카드 아래 지도와 목록을 기본 표시한다. 좌표를 찾지 못한 항목은 목록에 표시한다.
- 같은 좌표를 두 번 방문하면 각 방문 번호를 같은 위치에서 따로 선택할 수 있다.
- 초대장은 지도·요약과 동일한 방문 배열과 무장애 정보를 사용한다.

## How
- 기존 카카오맵 SDK를 사용한다. SDK 로드 후 장소 검색을 시작하고 요약 목록은 즉시 렌더링한다.
- 좌표가 없는 구간에서 연결선을 끊고, 핀을 키보드와 터치로 조작 가능한 버튼으로 제공한다.

## AC
- Given 연속하는 좌표 2개 이상. When 결과가 나온다. Then 번호 핀과 순서 연결선이 보인다.
- Given 지도 핀을 선택한다. Then 같은 번호와 이름, 무장애 정보가 팝업에 표시된다.
- Given 지도에서 찾지 못한 장소. Then 목록과 초대장은 그 장소를 유지한다.
