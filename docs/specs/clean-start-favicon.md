# 첫 화면 정리와 파비콘

## Why
첫 화면에서 검색 시작에 필요한 요소가 눈에 띄고 브라우저 탭에서 서비스를 식별할 수 있어야 한다.

## Goal
지역 선택기는 접힌 상세 설정 안에 둔다. 두 화면에 동일 아이콘을 적용한다. 백업 경로 삭제는 범위에서 제외한다.

## What
상단 백업 링크를 숨기고 검색 지역은 설정을 펼쳐 고를 수 있다. 위치 확인 후 재검색 버튼은 해당 상황에만 노출한다.

## How
메인과 백업 HTML에서 공통 SVG·ICO·Apple 아이콘을 참조한다. 단일 오프라인 HTML도 아이콘을 포함한다.

## AC
- 초기 화면에 지역 선택기와 백업 링크가 보이지 않는다.
- 상세 설정을 열면 지역을 변경할 수 있고 직접 백업 URL은 열린다.
- 두 화면에 16·32픽셀에서 식별 가능한 휠체어 아이콘이 적용된다.
