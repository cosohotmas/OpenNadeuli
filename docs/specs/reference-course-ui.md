# 3번째 버전 화면 반영

## Why
첨부 화면처럼 사용자가 요청 조건, 실제 조회 내역, 방문 순서와 접근성 정보를 쉽게 찾아야 한다.

## Goal
- 날짜마다 한 타임라인에서 두 핸들로 범위를 조절한다.
- 실제 조회 내역과 방문 카드, 동선 목록, 편집 가능한 초대장 미리보기를 제공한다.
- 범위 제외는 공개 API 키 설정, 실시간 데이터 활성화, 샘플에 없는 카페나 방문지 생성이다.

## What
- 입력창 위에 빠른 질문을 가로로 배치하고 일정 요약, 여행 종류, 날짜 선택을 제공한다.
- 응답에 요청 조건과 도구별 샘플 결과 건수, 방문 순번, 접근성 배지와 장소별 무장애 설명을 표시한다. 산책로는 경사·바닥·난간·휴식·화장실, 관광지·식당·숙소는 알려진 접근성 항목을 보여 준다. 확인값이 없으면 정보 없음으로 안내한다.
- 동선 목록에 카카오맵 링크, 안심 체크포인트와 초대장 버튼을 제공한다.

## How
- 기존 시간대 조건과 지도 컴포넌트를 사용한다. 시간 핸들은 기본 range 입력을 사용한다.
- API 응답에 선택적 카드 상세를 추가하고 기록된 조회 이벤트를 표시한다. 접근성 표시는 샘플의 긍정 값만 사용한다.

## AC
- Given 부산 코스 결과. When 결과를 읽는다. Then 방문 카드와 동선의 번호·순서가 일치하고 배지는 원본 필드에서 파생된다.
- Given 조회를 하지 않은 요청. When 과정을 표시한다. Then 조회 완료나 외부 API 호출 표시를 생성하지 않는다.
- Given 초대장 편집. When 문구를 바꾼다. Then 미리보기와 복사 대상이 같은 텍스트로 갱신된다.
