# 공공데이터 기반 코스

## Why
운영 방문자가 시연용 장소와 실제 공공데이터 후보를 식별하고, 접근성 원본에 없는 항목을 방문 전에 확인할 수 있어야 한다.

## Goal
- React와 정적 백업이 같은 코스 API와 데이터 출처 계약을 사용한다.
- 관광지 상세, 인근 식당·카페, 1박 2일 숙박을 공식 API에서 조회한다.
- 조회 실패와 정상 빈 결과를 구분하며, 운영 API의 가상 장소 대체는 0건이다.
- 범위 제외는 공식 최대 경사도 자료가 없는 탐방로, 예약·현장 보장, 캐시 서비스워커, 자동 운영 배포다.

## What
- 카드·도구의 `sourceType`은 `live_api`, `public_dataset`, `fallback_mock`을 지원한다. 공식 탐방로 파일을 연결하기 전에는 `public_dataset` 후보가 없다.
- `fetchedAt`은 UTC 조회 성공 시각이다. `sourceUpdatedAt`은 원본 수정 일시나 상권 기준월이며 없으면 null이다.
- 도구 상태는 `success`, `empty`, `unavailable`, `skipped`이다. 조회 실패 도구와 결과가 없는 도구를 각각 표시한다.
- 공급자 원본 필드만 `verifiedAttributes`로 전달한다. 출입구 턱, 숙소 객실·욕실 등 확인되지 않은 조건은 `verificationNotice`로 안내한다.
- 정상 빈 결과는 200과 빈 카드. 요청한 공식 조회가 모두 실패하면 503. 정적 백업만 연결·타임아웃·5xx 실패 시 `시연용 내장 샘플`을 표시한다.

## How
- 기본 API 경로는 `/api`이며 빌드에 `VITE_API_BASE`가 지정된 경우 공개 기준 URL을 변경한다.
- FastAPI는 서버 환경변수로 TourAPI와 상권정보를 호출한다. HTTPS 인증은 운영체제 신뢰 저장소 또는 서버에서 명시한 SSL 인증서 파일을 사용한다. 기존 로컬 키 이름은 호환 별칭으로 읽는다. 지도 JavaScript 키와 공공 API 인증키는 분리한다.
- TourAPI 목록 후보의 `contentid`로 상세 무장애 정보를 붙인다. 숙박은 `contentTypeId=32`이며 표기 가능한 항목은 원본의 제공 범위에 한정한다.
- 상권정보는 선정한 공공데이터 관광지 좌표 또는 요청 지역의 기준 좌표로 반경 600m를 조회한다. 업종 코드를 사용해 식당·카페를 구분한다. 기준 좌표 사용은 도구 로그에 표시한다.
- 부산 탐방로는 공식 최대 경사도 자료가 확정될 때까지 조회를 보류한다. 운영 코스는 선택 기간 내의 제안 시각과 좌표를 반환한다.
- 백업의 완전 오프라인 실행은 내려받을 수 있는 단일 HTML 빌드를 제공한다. 오프라인 지도 타일과 실시간 조회는 제공하지 않는다.

## AC
- Given 정상 공개 응답. When /api/course. Then 카드·도구 출처, 조회 시각·원본 기준일과 접근성 확인 안내를 반환한다.
- Given 정상 빈 응답. When 두 UI에서 검색. Then 빈 결과가 표시되고 시연 샘플은 생성되지 않는다.
- Given 연결 실패. When 백업으로 검색. Then 시연용 배지가 표시되고 샘플 코스가 실행된다.
- Given 부산 탐방로. When 코스 응답을 받는다. Then 공식 최대 경사도 근거가 없다는 도구 기록만 표시된다.
