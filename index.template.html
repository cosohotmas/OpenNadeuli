⚙️ 공공데이터 API 키 설정

인증키를 입력하면 공공데이터포털(data.go.kr) 실시간 조회를 시도하고, 실패하면 내장 샘플 데이터로 자동 전환되어 시연이 끊기지 않아요. 호출은 브라우저 직접 호출(data.go.kr CORS 허용) 우선이고 실패 시 serve.mjs 내장 프록시로 폴백합니다 — 터널·localhost 어디서든 테스트할 수 있어요 (file:// 직접 열기에서는 내장 데이터 사용). 키 발급: 포털 가입 → 아래 서비스 "활용신청" → 마이페이지 인증키. 키 없이도 모든 기능을 즉시 시연할 수 있어요.

※ 라이브 결과는 API가 무장애 상세를 제공하지 않을 수 있어, 카드에 "현장 확인 필요" 배지를 붙여 안전하게 표시합니다. 카카오 지도 키는 결과 하단 동선 지도에만 사용됩니다.
